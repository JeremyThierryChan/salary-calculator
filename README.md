# 时薪 / 月薪 换算计算器

一个零依赖的单文件网页计算器：按你**真实的工作制与每日工时**，把月薪折算成实际时薪（或反推月薪）。

打开 [`index.html`](index.html) 即可使用，无需构建、无需服务器、无第三方依赖。

> 🔗 在线体验：https://jeremythierrychan.github.io/salary-calculator/

---

## 为什么需要它

「月薪 1 万」在双休、单休和无休三种工作制下，是完全不同的价钱。招聘时谈的是月薪，实际付出的是工时——这个计算器把两者拉到同一个刻度上比较。

同样 1 万月薪（每月 30 天、每日 8 小时）：

| 工作制 | 每月工作日 | 每月总工时 | 实际时薪 | 折合标准工时制月薪 |
| --- | ---: | ---: | ---: | ---: |
| 5休2（双休） | 22 天 | 176 h | **¥56.82** | ¥9,886 |
| 5+6 大小周 | 24 天 | 192 h | **¥52.08** | ¥9,063 |
| 6休1（单休） | 26 天 | 208 h | **¥48.08** | ¥8,365 |
| 7+0（无休） | 30 天 | 240 h | **¥41.67** | ¥7,250 |

表面上都是月薪 1 万，实际时薪相差 **36%**。

## 功能

### 两个计算模式

顶部一键切换，输入框标签随模式自动变化：

| 模式 | 输入 | 输出 |
| --- | --- | --- |
| **月薪 → 时薪** | 月薪（元/月） | 实际时薪（元/小时） |
| **时薪 → 月薪** | 时薪（元/小时） | 对应月薪（元/月） |

### 输入项

- **主金额** — 按当前模式自动变成「月薪」或「时薪」；税前、到手均可，结果同口径
- **工作制** — `5休2` / `5+6大小周` / `6休1` / `7+0无休` 四个按钮
- **每月天数** — 默认 30（即 4 个整周 + 余 2 天），可改
- **每日工作时长** — 默认 8 小时，填**净工作时长**，不含午休
- **每月工作日数** — 两种方式，用下方的小开关切换：
  - **按工作制自动**（默认）— 由「每月天数 + 工作制」推算，结果一定是整数，输入框只读，并在下方显示推导过程，例如 `4 周 × 5 天 + 余 2 天 ＝ 22 天`
  - **手动输入** — 输入框可自由填写，适合按当月实际排班（含法定节假日、调休）计算

### 结果

主数字为时薪或月薪，并附一行可核对的算式。下方明细包含：

- 每月工作日 / 每日工时
- **每月总工时**
- 折算日薪
- 年收入（×12）与年总工时
- **折合标准工时制月薪（21.75 天 × 8h）**

最后一行是理解这份收入的关键：把算出来的实际时薪，放回法定标准月（21.75 天 × 8 小时 = 174 小时），看它等价于多少月薪。这样不同工作制之间就能横向比性价比。

## 计算公式

```
时薪 = 月薪 ÷（每月工作日数 × 每日工作时长）
月薪 = 时薪 × 每月工作日数 × 每日工作时长

折算日薪     = 月薪 ÷ 每月工作日数
折合标准月薪 = 时薪 × 21.75 天 × 8 小时
```

### 每月工作日数怎么算

默认每月按 **30 天** 计，也就是 **4 个整周 + 余 2 天**。

先算完整排班周期内的工作日，**余下的天数全部计入工作日**，所以结果一定是整数，不会出现 21.43 这种小数：

| 工作制 | 排班周期 | 推导 | 30 天下的工作日 |
| --- | --- | --- | ---: |
| 5休2（双休） | 7 天 / 5 个工作日 | 4×5 + 2 | **22 天** |
| 5+6 大小周 | 14 天 / 11 个工作日 | 2×11 + 2 | **24 天** |
| 6休1（单休） | 7 天 / 6 个工作日 | 4×6 + 2 | **26 天** |
| 7+0 无休 | 7 天 / 7 个工作日 | 4×7 + 2 | **30 天** |

当月天数不是 30 时（例如 2 月填 28），按同一规则重算：

```
每月工作日数 = 完整周期数 × 周期内工作日数 + 余下天数
```

> 若某月有法定节假日或调休，请切换到**手动输入**，直接填当月的实际排班天数。

## 本地使用

直接双击 `index.html`，或：

```bash
# macOS
open index.html

# 任意目录下起一个静态服务（可选）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

Pages 的部署来源已设为 **GitHub Actions**（Settings → Pages → Source），无需再手动配置。

之后每次 `git push` 到 `main`，Action 会自动重新构建并发布，访问地址：

```
https://jeremythierrychan.github.io/salary-calculator/
```

也可以在 **Actions** 标签页手动触发（`workflow_dispatch`）。

工作流只发布 `index.html`（先复制到 `_site/` 再上传），因此 README、LICENSE 和 workflow 文件不会出现在站点上。
