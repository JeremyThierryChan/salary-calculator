# 时薪 / 月薪 换算计算器

一个零依赖的单文件网页计算器：按你**真实的工作制与每日工时**，把月薪折算成实际时薪（或反推月薪）。

打开 [`index.html`](index.html) 即可使用，无需构建、无需服务器、无第三方依赖。

> 🔗 在线体验：https://jeremythierrychan.github.io/salary-calculator/

---

## 为什么需要它

「月薪 1 万」在双休、单休和无休三种工作制下，是完全不同的价钱。招聘时谈的是月薪，实际付出的是工时——这个计算器把两者拉到同一个刻度上比较。

同样 1 万月薪（每月 30 天、每日 8 小时）：

| 工作制 | 每月工作日 | 每月总工时 | 实际时薪 | 折合标准工时制月薪 |
| --- | ---: | ---: | ---: | ---: |
| 5休2（双休） | 21.43 | 171.4 h | **¥58.33** | ¥10,149 |
| 5+6 大小周 | 23.57 | 188.6 h | **¥53.03** | ¥9,227 |
| 6休1（单休） | 25.71 | 205.7 h | **¥48.61** | ¥8,458 |
| 7+0（无休） | 30.00 | 240.0 h | **¥41.67** | ¥7,250 |

表面上都是月薪 1 万，实际时薪相差 **40%**。

## 功能

### 两个计算模式

顶部一键切换，输入框标签随模式自动变化：

| 模式 | 输入 | 输出 |
| --- | --- | --- |
| **月薪 → 时薪** | 月薪（元/月） | 实际时薪（元/小时） |
| **时薪 → 月薪** | 时薪（元/小时） | 对应月薪（元/月） |

### 输入项

- **主金额** — 按当前模式自动变成「月薪」或「时薪」；税前、到手均可，结果同口径
- **工作制** — `5休2` / `5+6大小周` / `6休1` / `7+0无休` 四个按钮
- **每月天数** — 默认 30，可改（例如按 2 月填 28）
- **每月工作日数** — 由工作制比例自动算出，也可手动覆盖（例如按当月实际排班填 22 天）。手动修改后输入框会变黄并标记「已手动指定」
- **每日工作时长** — 默认 8 小时，填**净工作时长**，不含午休

### 结果

主数字为时薪或月薪，并附一行可核对的算式。下方明细包含：

- 每月工作日 / 每日工时
- **每月总工时**
- 折算日薪
- 年收入（×12）与年总工时
- **折合标准工时制月薪（21.75 天 × 8h）**

最后一行是理解这份收入的关键：把算出来的实际时薪，放回法定标准月（21.75 天 × 8 小时 = 174 小时），看它等价于多少月薪。这样不同工作制之间就能横向比性价比。

---

## 计算公式

```
时薪 = 月薪 ÷（每月工作日数 × 每日工作时长）
月薪 = 时薪 × 每月工作日数 × 每日工作时长

每月工作日数 = 每月天数 × 工作制比例
折算日薪     = 月薪 ÷ 每月工作日数
折合标准月薪 = 时薪 × 21.75 天 × 8 小时
```

工作制比例：

| 工作制 | 比例 | 30 天下的工作日 |
| --- | --- | ---: |
| 5休2 | 5 ÷ 7 | 21.43 |
| 5+6 大小周 | 11 ÷ 14 | 23.57 |
| 6休1 | 6 ÷ 7 | 25.71 |
| 7+0 无休 | 7 ÷ 7 | 30.00 |

> 按比例折算得到的是**月平均值**。若某月有法定节假日或调休，建议直接在「每月工作日数」里手动填当月的实际排班天数。

## 本地使用

直接双击 `index.html`，或：

```bash
# macOS
open index.html

# 任意目录下起一个静态服务（可选）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 部署（GitHub Pages）

仓库已配置 GitHub Actions 自动部署：**推送到 `main` 分支即自动发布**。

工作流文件：[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)

### 首次部署需要手动开启一次

`workflow` 方式部署必须先把 Pages 的源设为 GitHub Actions：

**Settings → Pages → Build and deployment → Source 选择 `GitHub Actions`**

之后每次 `git push` 到 `main`，Action 会自动重新构建并发布，访问地址：

```
https://jeremythierrychan.github.io/salary-calculator/
```

也可以在 **Actions** 标签页手动触发（`workflow_dispatch`）。
